Quick Start

Installation

Install dependencies, then drop the scripts into Nautilus' scripts folder.

bash 
# 1. Install dependencies
sudo apt install \
  docker.io \
  libimage-exiftool-perl \
  imagemagick \
  jpegoptim \
  python3

# 2. Clone the repo
git clone https://github.com/per2jensen/file-manager-scripts.git

# 3. Copy scripts to Nautilus
cp file-manager-scripts/scripts/* \
  ~/.local/share/nautilus/scripts/

# 4. Make them executable
chmod u+x ~/.local/share/nautilus/scripts/*

How to Use

Running a Script

Once the scripts are in place, using them is a right-click away.

01
Open Nautilus and browse to the directory containing your images.
02
Select one or more files.
03
Right-click and choose Scripts from the context menu.
04
Pick the script you want — the list reflects everything in ~/.local/share/nautilus/scripts/.
⚠
Some scripts modify the original file; others create a new file alongside it. Check the New file? column in the table above before running a script on originals you want to keep.
